# Reproducing the submissions

Run all commands from `experiments/20261008_full_subj0_deepnet/`. Set `PY` to your Python interpreter (default `python`).

## 1. Data

```bash
python sources/download_subj0.py        # subj0 runs from pnpl/LibriBrain and pnpl/LibriBrain2 -> data/raw/
python - <<'PY'
from huggingface_hub import hf_hub_download
for f in ["COMPETITION_HOLDOUT/subj00_holdout01_sentence.npz", "COMPETITION_HOLDOUT/subj00_holdout2_word.npz"]:
    hf_hub_download("pnpl/LibriBrain-Competition-2026", f, repo_type="dataset", local_dir="../../data/raw/LibriBrain-Competition-2026")
PY
python sources/preprocess.py            # 1 s epochs, 125 Hz, PCA 306 -> 80 (data/derived/subj0_pca_epochs)
python sources/preprocess_w3.py         # 3 s epochs [-0.5, 2.5] s, 50 Hz (data/derived/subj0_pca_w3; PNPL_FS=100 gives the 100 Hz variant subj0_pca_w3h)
```

## 2. MEG models

Every ensemble member is a tag. Each tag is trained by one `train_ctx.py` call (or a `pseudo_ft.py` call, for self-trained members), and its exact command line is in the `colab_*.sh` / `local_queue*.sh` script that produced it. Search the scripts for the tag name. Every run writes `outputs/<tag>/model.pt` and `outputs/<tag>/holdout_logits.npz`.

Naming conventions:
- `w3*`: 3 s models; `f*`: 1 s models.
- `p*`, `q*`, `r*`, `s*`, `t*`, `u*`: self-trained members.
- `L` and `M`: 12-layer models; `X`: the 16-layer model; `C`: the wide CNN; `I` and `G`: instance- and window-normalised models.

## 3. In-domain LMs

```bash
cp ../../corpora/*.txt outputs/
$PY sources/ft_vocab_lm.py --base gpt2 --corpus vocab_corpus_llm_plus.txt --out outputs/lm_gpt2_llm_plus   # 2,103 sentences
$PY sources/ft_vocab_lm.py --base gpt2 --corpus vocab_corpus_llm_big.txt  --out outputs/lm_gpt2_llm_big    # 3,742 sentences
```

Defaults: 3 epochs, lr 5e-5, batch 16, seed 0.

Corpus sources:
- `vocab_corpus.txt`: 807 sentences written by Claude (`sources/vocab_corpus.py`).
- `vocab_corpus_llm*.txt`: generated by Qwen3.5-9B (`sources/gen_vocab_llm.py`).
- `vocab_corpus_guided*.txt`: MEG-guided proposals (`sources/gen_guided.py`).

## 4. Best submissions

`S` is the IN1 list above and `ISO` is the isolated-word list.

```bash
# public 0.724: IN1 + in-domain GPT-2 (2,103) + GPT-2-medium
$PY sources/lm_fusion.py --tags $S --lm outputs/lm_gpt2_llm_plus --alpha 0.5 --beam 32 --soft --pmi --device cuda --out outputs/fused_IN1_llm_plus.csv
$PY sources/lm_fusion.py --tags $S --lm gpt2-medium            --alpha 0.5 --beam 32 --soft --pmi --device cuda --out outputs/fused_IN1_gpt2-medium.csv
$PY sources/lm_calib.py  --tags $S --mix outputs/fused_IN1_llm_plus_lmmix.npy outputs/fused_IN1_gpt2-medium_lmmix.npy --alpha 0.5 --out outputs/fused_IN1_Q_llm_plus.csv
$PY sources/make_final.py --fused outputs/fused_IN1_Q_llm_plus.csv --tags $S --iso_tags $ISO --tau 0.7 --out outputs/final_IN1_Q_llm_plus.csv

# guided proposals, then public 0.733: whole-sentence candidates, LM prior 0.5, lambda 0.3
$PY sources/gen_guided.py --sub outputs/final_IN1_Q_llm_plus.csv --k 6 --n_per 3 --out outputs/vocab_corpus_guided.txt
$PY sources/sent_cand.py --tags $S --corpus outputs/vocab_corpus_llm_big.txt outputs/vocab_corpus_llm_long.txt outputs/vocab_corpus_guided.txt \
    --base outputs/final_IN1_Q_llm_plus.csv --lm outputs/lm_gpt2_llm_plus --beta 0.5 --T 1 --lam 0.3 --out outputs/final_IN1Qp_SCGL_b0.5.csv
```

Running `sent_cand.py` again with the same inputs reproduces `final_IN1Qp_SCGL_b0.5.csv` exactly (maximum absolute difference 0.0). The ablations in the README vary `--corpus`, `--beta` and `--meg_w` (`--meg_w 0` drops the MEG term). LLM generation is sampled, so a new run of `gen_guided.py` gives a different proposal pool; the pools we used are included in `corpora/`.
